# Injective analytic mappings of low order

**Pablo Portilla Cuadrado**

The manuscript proves the following theorem by excluding orders 2, 3, and 4,
using the author's [reduction theorem](https://arxiv.org/abs/2610.10418v1).

> **Theorem.** Every holomorphic map germ
> $\boldsymbol{n}:(\mathbb{C}^2,0)\to(\mathbb{C}^3,0)$ that admits an injective representative
> has nonzero differential at the origin: $(d\boldsymbol{n})_0\ne0$.
